const getCategoryById = async (categoryId) => {
    const query = `
        SELECT category_id, name
        FROM public.category
        WHERE category_id = $1;

    const result = await db.query(query, queryParams);

Looking at this function, why did you decide to separate the SQL query into the `query` variable and pass `categoryId` inside the `queryParams` array using `$1`, instead of concatenating it directly into the SQL string?

### Topic 4: Error Handling

**Coach:** Finally, let's discuss **Topic 4: Error Handling**.  
Here is the error handling pattern implemented in your `server.js` (lines 52–73):

```javascript
// Catch-all route for 404 errors
app.use((req, res, next) => {
    const err = new Error('Page Not Found');
    err.status = 404;
    next(err);
});

// Global error handler
app.use((err, req, res, next) => {
    console.error('Error occurred:', err.message);
    console.error('Stack trace:', err.stack);
    
    const status = err.status || 500;
    const template = status === 404 ? '404' : '500';
    
    const context = {
        title: status === 404 ? 'Page Not Found' : 'Server Error',
        error: err.message,
        stack: err.stack
    };
    
    res.status(status).render(`errors/${template}`, context);
});
```

In this architecture, how does Express distinguish between a 404 Not Found and a 500 Server Error, and what is the benefit of centralizing error handling into a dedicated four-parameter middleware `(err, req, res, next)`?

**Student (David):** It is much more specific when showing where the error originated and its status code. This helps developers solve issues much more quickly and maintain a clear, organized view of the overall health of the website.

**Coach:** Exactly, David! Centralized error middleware ensures that every failure throughout the application flows through one unified pipeline. It logs diagnostic details and stack traces for developers while serving polite, secure error pages (`404.ejs` and `500.ejs`) to users, ensuring no sensitive credentials or raw stack traces leak into production.
